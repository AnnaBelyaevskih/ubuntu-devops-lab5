# Лабораторная работа №5: Работа с переменными и NMAP в Ansible

## Описание
- Установка сетевого сканера NMAP.
- Копирование локального файла со списком целей (`targets.txt`) на целевые хосты.
- Запуск сканирования NMAP с выводом результатов в greppable-формате.
- Вывод результатов сканирования в stdout через модуль `debug`.

---

## Структура проекта
- `playbook.yml` — сценарий автоматизации Ansible.
- `targets.txt` — файл со списком IP-адресов целей для сканирования.
- `README.md` — документация к лабораторной работе.
